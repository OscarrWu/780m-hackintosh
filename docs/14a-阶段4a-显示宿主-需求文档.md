## 1. 编写意图与文档定位

本文档是阶段 4a（显示宿主）的需求文档。它把 14 册 §3 的技术方向固化为**约束、可执行验收、禁止事项与阶段边界**；不含实现方法，实现方法归《阶段4a-技术方案》（本文档验收后编写）。MMIO 偏移数值、位域表、生成物清单归技术方案；本文保留寄存器名、语义与判定契约。

阶段 4a 的目标（引自 14 册 §2.1）：自建显示宿主，使 WindowServer 识别 IOFramebuffer 并在**软件合成**下得到可日常使用的桌面；完成口径为"看起来正常的 Mac"——开机进桌面、窗口拖动流畅、亮度可调、"关于本机"显示 780M。

读者与用途：主 agent（裁决与验收）；技术方案作者（在本文约束内设计）；实施程序员（按需求条目与 V 表交付）；上机操作者（执行 §6 的触发步骤）。本文档自包含，不要求读者先读《阶段4b-需求文档》；两篇的边界见 §3.2，交接点以文件名互指。

**"完成"的唯一判词**见 §6.2，任何章节的局部结论不得单独宣称本阶段完成。

## 2. 最高约束原则

沿用 `src/docs/00-总体路线.md` §0.2 四条最高原则（:17-20）与 §0.5 生产机六条（:52-57），不加改写。阶段 4a 追加：

- **P4A-1 依据优先**：一切 DCN 寄存器偏移、位定义与序列以 Linux v7.2 的 `dcn_3_1_4` 头（`dcn_3_1_4_offset.h`/`_sh_mask.h`）与 Linux 侧 `dcn314` 前缀源码为准（显示宿主调研 H-24～H-30）；无 Linux 出处的写不写码（`INV-A1`、`INV-A2`、`PC-7`）。
- **P4A-2 同模式优先**：接管不得改变固件已配置的时序、链路训练结果与像素格式；凡需改动时序或链路才能前进的场合，停并上报，不自行扩展 mode-set（原则一、原则二、14 册 §2.2）。
- **P4A-3 可回退不 panic**：任何显示写路径失败必须能退回固件帧缓冲画面，系统保持可用（原则三、`INV-B4`）。
- **P4A-4 单机数据不外溢**：本机实测值只作本机基线，不得进入通用驱动逻辑（`INV-A6`）；Cobalt64/nullarc 的数值一律标"对照值，需本机复核"（`PC-2`、`PC-8`）。
- **P4A-5 生产机纪律逐条适用**：先只读后写入、证据先落盘、一次开机一次触发、人在场、不合盖、触发一律手动且禁止 `n48r3-auto=1`（00 册 §0.5）。

## 3. 范围与非目标

### 3.1 范围

1. **显示宿主发布**：自建 IOFramebuffer 子类延续 GOP 画面，发布模式表与像素格式，提供亮度与翻页接口；GPUWrangler busy-hold 时序（14 册 §3.2、§3.5）。
2. **DisplayPipe 宿主与 AGDC**：自建 IOAccelDisplayPipe 子类作 display machine 挂点（trampoline 转发）；自建 AGDC 对象应答 WindowServer 的厂商查询（14 册 §3.3、§3.6）。
3. **DCN 3.1.4 寄存器层**：只读快照、写白名单、OTG/HUBP/DIO/PWRSEQ 最小内屏路径（14 册 §3.7）。
4. **同模式接管与硬件翻页**：表面接管、翻页位域、VBL 与帧计数、witness 证据链（14 册 §3.8）。
5. **背光**：由显示宿主直写 DIO link-encoder PWM 寄存器（14 册 §3.10）。
6. **安全网与回退**：看门狗、风暴保护、kill file、健康检查、NVRAM 标记与 boot-arg 回退（14 册 §3.9、§3.12、§7）。

### 3.2 非目标

- 任意 mode-set 能力（分辨率/刷新率切换、DSC、链路重训）；首期只接受固件已配置的原生模式（14 册 §2.2）。
- DPP/MPC/OPP/DSC 的**写路径**；若 F-03 取证表明确需读 DPP 方可确认 `fmt=8` 语义，仅允许**只读**扩展，写入仍禁止（主agent 裁定，见《编写决策记录》）。
- 外接显示器、多屏、DPMS/睡眠与显示电源管理（归阶段 6）。
- 加速器、TTL 对象、vtable hook、xlat 命令翻译、Metal/RADV 渲染接管（归《阶段4b-需求文档》与阶段 5）。
- 色彩管理与 EDID 覆盖（以本机 EDID/DPCD 为唯一基线，见 P4A-05）。
- **阶段边界**：AGDC 自建、IOFramebuffer 宿主类（含 `Navi48Framebuffer` 类本体）、DisplayPipe trampoline、显示宿主相关源在 rdna3 目标的构建接入，全部归本篇；4b 不重复实现（划分理由见《编写决策记录》）。

## 5. 需求条目

编号为组字母＋序号。每条三件事：需求（约束）、可执行验收、设计依据。**组内总约束**先于条目，是组内跨条不变量。验收的具体证据形态统一见 §6。

### A 组：显示宿主发布

**组内总约束**：宿主对象只回答查询与转发，不承担渲染；所有对象在 `stop`/`remove` 时释放并撤销注册（`INV-B4`、`INV-C4`）。

- **A1 IOFramebuffer 宿主发布**：自建 IOFramebuffer 子类（`Navi48Framebuffer` 类本体由本篇交付），boot 时从 `IOPlatformExpert::getConsoleInfo` 取 `Console,*` 几何，`built-in=true`，发布模式表至少含 2880×1800@90，并声明 `IOFBDependentID`/`IOFBDependentIndex`。**验收**：`ioreg` 可见该实例且模式表含该项；`system_profiler SPDisplaysDataType` 显示 780M；`TARGET=rdna3` 构建包含新增宿主源（Makefile 清单可查）。**依据**：H-64～H-67、F-12、G-04、14 册 §3.2。
- **A2 像素格式与模式查询契约**：`getDisplayModeCount`/`getCurrentMode`/`getPixelInformation` 全部实现，像素格式 32bpp 且仅报告本机实际格式；不得以基类默认实现返回 `kIOReturnUnsupported` 掩盖缺项。**验收**：`ioreg` 与 `system_profiler` 的像素格式/刷新率一致；查询接口无未实现返回。**依据**：H-66、`INV-B1`。
- **A3 DisplayPipe 宿主与 trampoline**：自建 IOAccelDisplayPipe 子类作 display machine 挂点，内部以 trampoline 转发到 bringup kext 的 ops 表；selector 编号沿用既有分配，不新增私有 selector 形态。**验收**：pipeadopt 路径的转发计数随 present 增长并落证据键。**依据**：H-47～H-49、F-13、`LY-11`、`INV-A7`。
- **A4 AGDC 服务**：自建 AGDC 对象，应答厂商命令 1／0x980／0x921／0x711，返回框架缓冲与显示管信息；Ventura 的基类尺寸与钩子槽按 F-10 重测后实现（不得沿用 Tahoe 槽位）。**验收**：WindowServer 启动日志无 "Unable to find display pipe"；厂商命令有应答计数。**依据**：H-60～H-63、F-10、14 册 §3.6。
- **A5 GPUWrangler busy-hold**：宿主启动即 `adjustBusy(1)`，arming 完成后 `adjustBusy(-1)`；120 秒定时器兜底，超时只释放不阻断 boot；`stop` 时必须释放。**验收**：boot 后 accelerator 记录不为 "no accelerator"；超时释放有日志。**依据**：H-70、F-11、14 册 §3.5。

### B 组：DCN 3.1.4 同模式接管

**组内总约束**：只写 §3.1 允许的寄存器组；任何 OTG timing 写入超出本篇范围；所有写经地址分类器与写白名单（`IO-3`、`IO-4`）；dcn41/RDNA4 的寄存器表、几何常量不得直接用于本机（`INV-A6`、D-5）。

- **B1 只读快照**：按 H-24～H-30 读 OTG0（H/V total、control、frame count）、HUBP0（表面地址/格式/tiling/CNTL）、DIO/DIG/DP 链路、PWRSEQ0 PWM，落 `N48R3EVID-DCN-SNAPSHOT`。**验收**：`n48r3test dcnstate` 输出与阶段 0 快照逐项一致，差异项为零。**依据**：H-14～H-30、`IO-2`。
- **B2 段基址与勘误**：段基址采用 seg0/1/2＝0x12/0xC0/0x34C0；`machine-config.md:124` 错标登记勘误（原行保留＋旁注）；seg3/seg4 与 DPP/MPC/OPP 覆盖按 F-01 闭合后才可纳入只读快照（写入仍按 §3.2 非目标禁止）。**验收**：读值与 Linux 头推算一致；勘误条目落盘。**依据**：H-30、D-3、F-01。
- **B3 写路径门禁**：所有 DCN 写必须经地址分类器与白名单；分类器只做判定，不执行 I/O、不定时序、不分配内存；写被拒以具名错误失败并计数；只读层的 `E_NOWRITE` 不得被调用方当作成功。**验收**：命名拒绝块有样本；故意越界写被拒且子步具名失败。**依据**：H-76～H-77、`IO-3`、`IO-4`、`IO-6`。
- **B4 同值写回验证**：用同值写回档（D-2：不改时序、不取 OTG update lock 作全局锁、不改 `v_total`）证明对 DCN 状态的理解：抓取→原值写回→再抓取→逐 dword 比对。**验收**：比对全等，帧计数器继续走无 stall。**依据**：H-52～H-55、D-2。
- **B5 GOP 配置完整性判定**：在写任何 HUBP 表面前判定固件配置是否完整（fmt=8、tiling、DCC、pitch 语义按 F-03/F-06 取证）；判定为不完整时停并上报，不自行补 mode-set（允许按 §3.2 条件只读扩展 DPP 以确认语义）。**验收**：判定结论与读值一并落盘；判定为不完整时无任何写发生。**依据**：H-17～H-18、F-03、F-06、14 册 §2.2。
- **B6 链路一致性**：接管前确认 DP0 `link_up=1`、DIG0 前后端使能、DIO 链路与本机 eDP 的对应关系（按 F-02 澄清，不以"需重新配 DIO"为前提）。**验收**：`dcnstate` 链路项与 EDID/DPCD 一致。**依据**：H-17～H-19、F-02、D-4。

### C 组：翻页扫描与 VBL

**组内总约束**：翻页必须可证明、可恢复；任何"写了就算成功"的实现视为不通过（D-6）。

- **C1 HUBP 表面接管**：将渲染目标缓冲地址写入 `SURFACE_ADDRESS_HIGH`/`LOW`（先高后低，写 low 自动锁存），除翻页位域外不改 `surface_config`。**验收**：翻页后 `EARLIEST_INUSE` 更新为写入地址。**依据**：H-31、H-32、H-36。
- **C2 翻页位域与 pending 判据**：`FLIP_TYPE`/`FLIP_PENDING`/`UPDATE_LOCK` 位域按 H-25/H-28 使用；pending 判据为 `FLIP_PENDING` 为真或 `EARLIEST_INUSE ≠ 本帧地址`；只读寄存器表须补 `FLIP_CONTROL`/`FLIP_PENDING`（当前缺失，G-01）。**验收**：翻页后 pending 置位并在下一帧清除，两项判据同时成立。**依据**：H-31～H-35、H-51、G-01、F-04、F-05。
- **C3 翻页 witness**：以 Cobalt64 七位掩码（H-54）承载翻页证据：pending 置位、pending 清除、`EARLIEST_INUSE` 等于测试地址、地址恢复原值、CRC 变化、CRC 回归、console CRC 稳定。七位为 14 册 `:152` 五项核心证据的超集（加严），五项中的"帧计数器继续走"作为独立判据一并检查；hold 超过 30 秒拒绝翻页。**验收**：`n48r3test flip` 输出七位掩码全中，且帧计数无 stall。**依据**：H-54、14 册 §3.8。
- **C4 TMZ/DCC 位保持**：翻页写地址时不清零 `surface_config` 的 TMZ/DCC 位；`restore_exact` 显式把 TMZ 写回 0。**验收**：翻页前后 `surface_config` 读回位域不变；restore 后与快照逐位相等。**依据**：H-36、H-55。
- **C5 VBL 与帧计数**：帧计数以 OTG `STATUS_FRAME_COUNT` 低 24 位为准；VBL 中断只作可选通知，不作 fence 依赖。**验收**：`dcnvbl` 计数与 90Hz 匹配（±1%）。**依据**：H-15、H-58、阶段3 先例 D4。
- **C6 扫描输出图案校验**：A/B 两缓冲写不同图案并翻页，CRC 比对；交付路径不得引入 CPU 拷贝帧。**验收**：CRC 变化且切换后画面正确。**依据**：H-50、14 册 §3.4、§3.8。
- **C7 扫描缓冲几何门**：翻页目标缓冲须过几何门：线性（SW_MODE=0）、无 DCC、ARGB8888、pitch 与宽高在驱动支持上限内（上限值按 F-07/Linux 依据定，不搬 64 KiB 等未取证常量）；不过门即拒绝并具名报错。**验收**：越界几何（超宽/超 pitch）被拒；合法几何通过。**依据**：F-07、`INV-B1`、14 册 §3.4。

### D 组：背光

**组内总约束**：亮度只经 PWRSEQ0 PWM；任何亮度动作不得引发模式切换或翻页；写前必须可读、写后必须读回（`INV-C1`）。

- **D1 PWM 寄存器路径**：由显示宿主直写 DIO link-encoder PWM（`BL_PWM_CNTL`/`CNTL2`/`PERIOD_CNTL`），置 `BL_PWM_EN=1`，周期与位宽按 pwrseq0 实测（period=4000、bitcnt=12）设定。**验收**：亮度调节生效且寄存器读回与写入一致。**依据**：H-39～H-42、H-20、F-08。
- **D2 level 语义与极性**：level/period 的语义与极性以 F-08 取证结论为准，不得把任意常量直接当百分比；F-09 的锁位域同理。**验收**：0%/50%/100% 三档实际亮度单调变化。**依据**：H-21、H-43、F-08、F-09。
- **D3 寄存器锁**：写 PWM 前按 F-09 的位域解除 `BL_PWM_GRP1_REG_LOCK`，写完恢复。**验收**：连续 100 次调节无锁死、无写被拒。**依据**：H-41、F-09。
- **D4 亮度接口**：宿主提供 set/get 亮度，底层直写 DIO PWM；最低亮度不闪，重启后亮度保持。**验收**：亮度键/滑块生效、最低亮度无闪烁、重启后亮度保持。**依据**：H-43～H-46、14 册 §3.10。
- **D5 不引入 ACPI/AUX-DPCD 背光路径**：PNLF 为无 `_BCL/_BCM/_BQC` 的壳设备，Apple 原生亦无 AUX-DPCD 背光路径。**验收**：代码无 `_BCL/_BCM` 依赖（检索零命中），背光仅经 PWM 寄存器。**依据**：H-13、14 册 §3.10。

### E 组：共存与回退

**组内总约束**：回退路径优先于任何功能推进；每个开关必须能单独生效并留证据；失败后不得在同一次启动内重试（`BV-14`）。

- **E1 boot-arg 回退族**：`n48r3-dcn=0` 不接管 DCN、宿主退回纯 GOP 延续；`n48r3bringup=0` 整体不加载；命名与三态语义按 `PC-11`。**验收**：两种取值下均能进入桌面，`ioreg` 状态符合预期。**依据**：14 册 §7、`PC-11`。
- **E2 NVRAM 标记法**：本次 boot 显示失败写标记，下次 boot 跳过接管直接用固件帧缓冲；标记一次消费即删，删不掉则不接管；变量名采用 `n48r3-*` 族，机制照 nullarc `phxfb-boot`（不沿用其变量名）。**验收**：人为制造失败后，下次 boot 直接用固件帧缓冲且有日志。**依据**：H-64、H-65、F-15、14 册 §3.12。
- **E3 kill file**：`/var/tmp/n48r3-noflip` 存在时内核侧拒绝翻页；落点用 `/var/tmp`，不用 `/tmp`。**验收**：创建该文件后 flip 请求被拒并记日志。**依据**：H-59、14 册 §3.9。
- **E4 与其他 IP 共存**：接管流程不得改动阶段 3 已建立的 VM/队列状态；DCN 时钟/电源是否由固件保持按 F-14 取证，若必须改动时钟/电压则停并上报（`IO-5` 禁止域）。**验收**：接管后 compute 闭环仍通过；无电源管理域写入。**依据**：F-14、`IO-5`、§3.3。
- **E5 回退后一致性**：emergency restore 必须完整写回快照（`FLIP_TYPE=0`、viewport start=0、TMZ=0、地址恢复）；restore 连续失败两次即停，不重试。**验收**：restore 后 surface 寄存器逐项等于快照；失败两次后进入 latch 且不再写。**依据**：H-55、`PC-12`、`INV-B4`。
- **E6 panic 自动回退**：显示路径 panic 后下次 boot 自动回固件帧缓冲，不重试接管（与 E2 NVRAM 标记协同，panic 路径也要能写标记或等效标记）。**验收**：模拟失败后连续两次 boot 均停在固件画面、无接管尝试日志。**依据**：H-64、14 册 §3.12、`INV-B4`。

### G 组：安全网、开关与失败停

**组内总约束**：安全网只做"保命与可回退"，不承担"修功能"；任何安全网动作不得导致 panic（原则三、`INV-B3`）。

- **G1 帧计数 stall 看门狗**：翻页接管后按 50ms 周期轮询 OTG 帧计数；连续无进展即 emergency restore 并 latch off 翻页路径；轮询上限与恢复次数按 3.1.4 复核后固定。**验收**：stall 注入后看门狗在有限轮询内恢复快照并 latch，屏幕不黑死。**依据**：H-57、14 册 §3.9。
- **G2 中断风暴保护**：阈值采用 1000 次/秒（裁决 D-1），超阈值关闭中断源并记日志。**验收**：风暴注入后中断源被关闭、系统保持可用。**依据**：H-58、D-1。
- **G3 健康检查**：`n48r3test health` 以 30 秒只读轮询 VM fault／HUNG／pid／HUBP underflow，四项全绿才可宣称稳定。**验收**：health 四项全绿。**依据**：14 册 §6.1（`:283`）。
- **G4 分级 latch**：翻页失败 latch `flip`，接管失败 latch `adopt`；任一 latch 不得自动解除，解除须有新证据。**验收**：latch 状态可读且重启前不自动清除。**依据**：`PC-12`、`INV-B3`。
- **G5 不 panic**：所有等待有界，失败返回具名错误；强制断电不是常规路径。**验收**：H4 故障注入矩阵无一 panic。**依据**：`INV-B3`、`INV-B4`、原则三。
- **G6 缺输入即停**：白名单拒绝、门禁不通过、快照缺失，均在第一个风险动作前以具名错误停止并指名缺失项。**验收**：缺输入场景下写计数为 0。**依据**：`INV-B1`、`INV-B2`。
- **G7 危险写默认关**：接管、翻页、背光写、AGDC 安装均为默认关的实验路径，须显式 arm 才可执行；禁止开机自动触发，`n48r3-auto=1` 一律拒绝。**验收**：默认启动不写任何显示寄存器；带 `n48r3-auto=1` 启动时实验路径仍关闭且有拒绝日志。**依据**：`INV-D4`、`INV-D5`、`INV-D8`、`PC-11`、00 册 §0.5。
- **G8 idle 恢复**：翻页路径连续无 scanout 调用超时（量级按 Cobalt64 对照值 `kIdleNs=5s` 复核）即恢复 console 表面地址，防持锁与画面漂移。**验收**：空闲超时后表面地址自动恢复且画面无抖动。**依据**：H-57、`INV-B4`。

### I 组：提交卫生

**组内总约束**：一次提交只对应一张任务卡与一组证据；不可追溯的改动不提交。

- **I1 一卡一提交**：提交信息含改动、通过标准、回退方式。**验收**：每个提交可在验收记录中回溯到一个需求条目；单提交只含一个逻辑改动。**依据**：`PC-10`、00 册 §9.3。
- **I2 每提交附证据**：以证据键或日志指针附着。**验收**：提交说明中的证据指针可解析到实际产物；缺失即不合并。**依据**：`PC-10`、`IO-2`。
- **I3 复用标注**：复用 Cobalt64/nullarc 片段须标注来源与许可证状态。**验收**：仓库内检索可定位每个复用片段的来源标注。**依据**：`PC-8`。
- **I4 不提交敏感与生成物**：固件、Apple 捕获件、构建产物，以及本阶段采集的 EDID/DPCD 原始二进制与反汇编导出，均不入库。**验收**：提交清单中不含上述类型文件。**依据**：`PC-9`。

### 6.2 唯一判词

当且仅当 V4A-1～V4A-15 全部 PASS、性能守门四项达标、soak 两次开机独立通过，方可宣称"阶段 4a 完成（看起来正常的 Mac）"。局部条目通过、单次开机通过、或性能守门未测，均不得宣称完成；不允许"基本可用""桌面能用即可"等模糊结论。

### 6.3 失败预案

| 失败模式 | 识别 | 处置 | 回退目标 |
|---|---|---|---|
| 快照读值漂移 | V4A-1 差异项非零 | 停，复核固件是否重新配置 | 不接管，保持 GOP |
| 同值写回比对不等 | V4A-3 出现差异 dword | 停，定位段基址/位域错误 | 不接管 |
| 翻页 witness 不齐 | V4A-4 位掩码缺项 | 立刻 restore，latch flip | 退回原表面地址 |
| 翻页 pending 不消 | pending 持续置位 | 核 FLIP_PENDING 位域（G-01、F-04）；退回 EARLIEST_INUSE 单侧判据并上报 | 退回原表面地址 |
| 花屏/错帧 | 画面异常但未停扫 | 核几何门与 pitch/对齐（C7、F-07）；核 fmt 语义（F-03） | 回退同模式只读 |
| 帧计数 stall | G1 看门狗触发 | emergency restore + latch | 固件画面 |
| AGDC 无应答 | V4A-7 日志出现缺 pipe | 停，按 F-10 重新取证 | 软件合成不可用即退回 GOP |
| AGDC 应答后 panic | 应答即崩 | 立即停用自建 AGDC；核类尺寸/槽位（F-10） | 退回 GOP 等待修复 |
| 背光写无效 | V4A-8 读回不一致 | 停背光，保留显示；核 PWM 量纲（F-08），不逐档盲试 | 保持固件亮度 |
| 中断风暴 | G2 触发 | 关闭中断源并记窗口计数，分析 DCE IRQ 来源 | 系统保持可用 |

### 6.4 soak 与性能守门

soak 与性能守门沿用 14 册 §6.3：fence <1ms、`vkprobe` 256/256、窗口拖动无可感知卡顿、90Hz 实际扫描无降档；soak 为连续 ≥30 分钟 × 2 次开机，4a 独立计数。性能守门不达标不得以"软件合成本就慢"为由豁免——本阶段的完成口径已包含"窗口拖动流畅"。

## 7. 禁止事项与失败流程

### 7.1 禁止事项

沿用阶段3 先例 §7.1 八条形态，逐条挂接 spec 编号，并追加本篇特有条款：

1. 不猜寄存器偏移与段基址（`INV-A1`、`INV-A2`）；无 Linux 出处不写码（`PC-7`）。
2. 不改 Apple 二进制（`INV-A4`）；本篇预计无 vtable 改动，条款延续有效。
3. 不跨阶段实现（§3.2 非目标）；不提前引入 4b 的 TTL/hook/xlat 内容。
4. 不默认开启 boot-arg；三态语义按 `PC-11`，实验与诊断默认关闭，禁 `n48r3-auto=1`（G7）。
5. 不自动重启；触发一律手动（`BV-13`）；失败后不重复触发（`BV-14`）。
6. 不放宽校验让测试通过；生成物不手改（`INV-A5`）。
7. 未验证结论标"待取证"（`INV-A3`）；Cobalt64/nullarc 数值标"对照值，需本机复核"（`PC-2`、`PC-8`）。
8. 提交规范按 `PC-10` 与 00 册 §9.3。
9. **本篇特有**：不做任意 mode-set、不改时序、不重训链路（P4A-2）；不以 CPU 拷贝帧作为交付路径（14 册 §3.4）；不建第二套写路径或私有日志缓冲（`IO-3`、`IO-7`）；未过 `dcnstate` 只读门槛不写 DCN（00 册 §0.5-1、`BV-11`）；不把单机实测值写进通用逻辑（`INV-A6`）；未取证段基址/未回填白名单不写寄存器（`INV-B1`、`IO-3`、`IO-4`）。

### 7.2 失败流程

记录 → latch off（flip／adopt 分级）→ 回退（`n48r3-dcn=0`／`n48r3bringup=0`／NVRAM 标记／kill file）→ 回顾（失败模式入 00 册附录 C）→ 不掩盖。失败后机器必须保持可用（`INV-B4`）；强制断电是最后手段。

## 9. 术语


| 术语 | 含义 |
|---|---|
| 同模式接管 | 不改固件已建立的显示时序/链路配置，仅接管表面地址与翻页的路径 |
| OTG／HUBP | DCN 的时序生成器／超像素管线（表面采样）两个编程块 |
| DIO／DIG／DP | 显示输出（编码器／数据通路／DisplayPort 控制器）链路组件 |
| PWRSEQ | 背光时序控制块；本机背光走 PWRSEQ0 的 PWM 寄存器 |
| surface flip／FLIP_PENDING／EARLIEST_INUSE | 翻页三要素：提交新表面地址、硬件的完成标志、最早在用地址（判据之一） |
| witness | 翻页证据的七位掩码（见 C3），全中才算接管成立 |
| 几何门 | 翻页目标缓冲的合法性检查（线性/无 DCC/格式/pitch 上限） |
| arming／busy-hold | 显式武装实验路径／以引用计数占用设备防休眠的机制 |
| latch | 失败锁：触发后重启前不自动解除 |
| kill file | 存在即禁用某路径的标志文件（`/var/tmp/n48r3-noflip`） |
| NVRAM 标记 | 本次失败写标记、下次 boot 跳过接管的回退机制 |
| idle 恢复 | 长期无扫描输出时自动恢复 console 表面地址 |
| soak | 长时间连续运行验证（≥30 分钟 × 2 次开机） |
