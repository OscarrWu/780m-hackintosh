# xlat11 skeleton register seed list (GFX10.3 source dialect).

# One gfx10.3 register NAME per line. This file is the xlat11 analogue of
# xlat12's "which registers does Apple emit" inputs (mtl-regrecs.txt /
# pm4census.txt), which are NOT available for RDNA3 yet (see
# evidence/src/INDEX.md and docs/Cobalt64-RDNA3-阶段1-技术方案.md §4.9).
#
# Stage-1 scope: the core draw / shader path plus one deliberate example of
# every Xlat11Class (identical, moved, field_repack, absent, legacy_vs,
# reused) and the NGG trap register. Stage 3 expands this list to the full
# Apple-emitted set captured on the target machine. Names MUST exist in
# gfx103.json; the generator refuses (exit 2) otherwise.
